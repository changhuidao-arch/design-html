## 本次调整

- 导航：浅灰侧栏与独立主内容区，任务、运行、证据层级分开。
- 任务列表：原生数据表，固定列角色、行分隔、父子任务缩进、业务状态、运行次数与关注情况独立列；查询与筛选进入 URL。运行次数来自真实任务详情，不用监控抽样数冒充完整历史。
- 调用流程图：保留节点、服务端关系、连线下钻、筛选、缩放、专注图谱与选中定位；改为已确认调用链分组，未关联运行单独分区；选中只改变高亮，不重排节点。默认不铺满长连线摘要，仍可开启。
- 运行详情：默认保留调用图与详情上下文，可主动展开运行详情；输入输出、时间瀑布图、执行记录、执行概览分别有入口。
- 时间瀑布图：继续使用原版完整组件及同版本本地 widget；支持完整时间轴、缩放、筛选、片段选择和证据定位，没有替换成静态示意条。
- 运行时间线：保留等待与执行区间；默认全部历史。选择最近 24 小时时明确解释历史记录被过滤，避免误报数据不可靠。
- 其余模块：保留原版异常提醒、历史失败、性能与用量、运行时表格和各自状态，统一分区与视觉规则。

## 两轮评审与修正

第一轮发现：表格行按钮受到旧布局选择器影响，任务文字被分配成多个窄列；原图排布行距过大且独立节点混入调用链；详情内输入输出与瀑布图的阅读顺序不清；窄屏旧头部网格拉伸按钮。

第二轮分别修正表格选择器优先级与列宽、按真实关系连接分组并验证选中前后位置、增加独立时间瀑布图入口、用明确白底操作区替换旧头部样式。已在浏览器重新检查。

艺术与阅读视角：用白底、浅灰画布、组标题、状态标签和编号等宽建立数据区分。工程视角：验证边来源、节点包围盒与滚动边界。任务所有者视角：四模块完整、两类时间图与调用图可达、结果与业务验收分开。

## 实际边界

这是可交互的静态对照稿，未替换已安装插件。页面“在线”、性能用量与状态均属于快照时点；刷新不联网采集，系统写操作被本地适配器拦截。当前仅包含已采集的工作区；切换其他工作区和保存连接设置不能产生真实数据。本机 CLI 原生采集未包含，保留缺失说明。桌面宿主原版截图曾捕获超时，未做逐像素比对。
