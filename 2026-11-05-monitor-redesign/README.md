## 设计读取与功能契约

面向任务管理者、开发人员的智能体任务监控工作台。默认拨盘：视觉冒险度 3、动效强度 2、信息密度 5。三秒内辨认任务业务状态、当前所选运行及下一步；任务、运行、执行过程和原始证据有明确层级。选运行时保留上下文；历史结论不冒充当前任务结论。

## 四个独立方向

- A「任务工作台」：现代亮白与原版橙色重音，任务 / 运行关系 / 结果三栏。推荐，优先解决层级与位置感。
- B「运行调度台」：深炭灰工程调度视图，等宽数字，实际起止时间泳道。优先排查耗时与并发。
- C「任务审阅册」：暖纸、宋体短标题、单栏编辑正文与事实边注。结论先行，适合审阅与验收。
- D「证据索引」：灰绿工程档案、方角索引、双栏记录与证据归属。适合按运行定位来源。

每个方向使用独立 brief、作用域 CSS 与局部事件。A/B/C 按技能要求分别由独立子代理生成，主流程负责 D、整合、数据核验和浏览器 QA。未调用外部模型。
